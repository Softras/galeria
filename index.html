Como publicar seu site (Deploy Grátis)

Para enviar este site para a pessoa que vai baixar as fotos, você pode usá-lo com suas próprias fotos de duas formas:

1 Opção 1: Netlify Drop / Vercel (Sem código)

  1. Salve este arquivo como index.html.
  2. Acesse o Netlify Drop.
  3. Arraste a pasta que contém o arquivo index.html para o site.
  4. Seu link público será gerado em instantes!

2 Opção 2: GitHub Pages

Crie um repositório no GitHub, faça o upload do arquivo index.html e ative o GitHub Pages nas configurações do repositório.

Dica Importante para Fotos Estáticas

Quando você faz upload pela tela, as imagens ficam visíveis apenas no seu navegador. Se quiser que outras pessoas vejam as fotos automaticamente ao abrir o link enviado, coloque as imagens numa pasta chamada images/ e substitua a lista inicial no código JavaScript do arquivo.
